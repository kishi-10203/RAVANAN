# Learning Agent 
- Runs `Locally` in my machine 
- Subordinate to `RAVANAN`
- helps me make `notes & format` as per `my requirement`.
- service runs in `docker`

---

## Tech Stack

| Layer | Technology | Responsibility |
|---|---|---|
| Programming Language | Python | Application development |
| Package Manager | uv | Dependencies, virtual environments, and lockfiles |
| Backend | FastAPI | Application API and orchestration interface |
| Frontend | Streamlit | User interface |
| LLM Runtime | Ollama | Local inference |
| Initial Model | Qwen 3.5 4B | Note analysis, generation, and preference learning |
| Data Validation | Pydantic | Structured data validation |
| Configuration | YAML | Learning preferences and application settings |
| Persistent Storage | SQLite | Feedback, history, and learning records |
| Document Format | Markdown | Input and output documents |
| Containerization | Docker | Application packaging |
| Service Orchestration | Docker Compose | Application deployment |
| Testing | pytest | Automated tests |
| Code Quality | Ruff | Linting and formatting |
